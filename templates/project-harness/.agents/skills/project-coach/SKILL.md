# Project Coach

Follow this workflow before implementation:

1. Read `AGENTS.md`.
2. Read `docs/PROJECT_BRIEF.md`.
3. Read `docs/ACCEPTANCE_CRITERIA.md`.
4. Read `docs/DEMO_SCRIPT.md`.
5. Identify the smallest next red/green milestone.
6. Ask before broadening scope.

When the user asks for implementation, keep the change tied to one acceptance criterion.
