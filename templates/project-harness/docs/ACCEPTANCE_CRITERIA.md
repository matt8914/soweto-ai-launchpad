# Acceptance Criteria

These criteria define green.

## Must Be True Before Pitching

- [ ] The project can be opened locally.
- [ ] The first screen or first flow explains the target user and problem.
- [ ] The core demo flow is visible.
- [ ] The demo uses fictional data.
- [ ] The team can explain what is real and what is mocked.
- [ ] The pitch names a practical next step after the event.

## Red/Green Milestones

| Status | Check | Command or manual step | Notes |
| --- | --- | --- | --- |
| Red | First core flow check | `[command or manual step]` | `[why it is red]` |
| Green | First core flow check | `[command or manual step]` | `[proof]` |

## Cut Line

If time is short, cut anything that does not help the core demo flow.
