First Time Using Codex

A simple cheat sheet for 35 students in 5 groups of 7.

What is Codex?

Codex is an AI build partner. It can help write code, fix errors, run checks, explain files, improve design and prepare a demo.

Your job: choose the problem, steer the work, check the result.

Today's mission

Build one small demo. Not a perfect app.

  • One real problem
  • One clear user
  • One useful action
  • Fake data only

Give every person a role

Driver: types into Codex Problem owner User owner Tester Designer Pitch lead Timekeeper

A [specific person] in Soweto struggles with [specific problem], so our app helps them [specific result].

First prompt to paste into Codex

We are using Codex for the first time.

We are a team of 7 students in the Boundless Soweto AI App Development Challenge.

Our problem is: [write the problem]
Our user is: [write the person]
Our app should help them: [write the result]

Please explain the plan in simple language. Then help us build the smallest demo version of this app. Teach us what you are doing as you go. Use fake data only. Do not use real personal data.

Three Codex moves

Plan mode: use when confused. Ask Codex to think before editing.

Goal mode: use when you know the outcome and need Codex to keep working.

Side chat: ask for status or explanation without stopping the build.

Build One Useful Demo

Pick one problem. Build one flow. Explain it clearly.

Possible demo ideas

  • Safety: fictional safety report plus useful contacts.
  • Healthcare: affordable care finder with fake data.
  • Missing people: fictional case tracker and reporting steps.
  • Traffic: delay report board or route status page.

Important safety rule

For safety, healthcare and missing people, this is a prototype. Do not promise emergency response.

Use no real names, photos, ID numbers, phone numbers, addresses or medical details.

Ask Codex for the next step

Build the first screen for this demo.
Run the app locally and tell us the link to open.
The app has an error. Read the error and fix it step by step.
Make the screen easier for judges to understand in 30 seconds.
Create a 5-minute pitch based only on what our demo actually does.
We have little time. What is the fastest fix so the demo still makes sense?

Green means ready enough

  • The app opens.
  • The main screen is clear.
  • One user can complete one action.
  • All data is fake.
  • The team can explain the problem.
  • The team can say what they would build next.

If stuck, paste this

We are stuck and we are beginners. Explain the problem simply. Then choose the fastest next step and do it. We need a demo more than we need a perfect app.

Remember

You do not need to know everything. Start with the problem. Tell Codex what you want. Let Codex help you build one useful thing.
