# 35-Minute Masterclass Guide

Time: 10:05-10:40  
Audience: 50 unemployed IT graduates at Boundless Soweto Campus  
Purpose: give participants enough confidence and structure to use Codex well during the build sprint.

## 10:05-10:10 - The Shift

Message:

- You do not need to wait for permission to start building.
- Codex can help with code, tests, docs and debugging.
- Your job is to steer: choose the problem, define success and review the work.

Say:

```text
Today you are not learning to type faster. You are learning to steer better.
```

## 10:10-10:18 - Business Before Code

Use this sentence:

```text
A [specific person] in Soweto struggles to [specific job], so our app helps them [specific result].
```

Examples of “specific”:

- a clinic visitor trying to find the right queue
- a spaza owner tracking stock
- a graduate preparing for an interview
- a learner who needs homework help

The team must choose one user and one core flow.

## 10:18-10:26 - Harness Engineering

Explain:

- The app is what you build.
- The harness is how you prove it works.
- Codex works better when it can read the rules, checks and acceptance criteria.

Show:

- `AGENTS.md`
- `docs/HARNESS_ENGINEERING.md`
- `docs/CODEX_MODES.md`
- `templates/project-harness/`

## 10:26-10:34 - Codex Operating Moves

Teach four moves:

- Plan mode: think before edits.
- Goal mode: hold the outcome steady.
- Side chat: ask for status or explanation without derailing the main task.
- Subagents: ask Codex to split independent review or exploration work when useful.
- Red/green: define a check, see red, make the smallest change, get green.

## 10:34-10:40 - First Team Action

Every team opens this repo in Codex and pastes:

```text
Read this repo and explain harness engineering to our team in plain language. Then help us choose or sharpen one app idea, create the smallest useful harness, and start building the first demoable version. Teach us what you are doing as you go.
```

Close with:

```text
If you can describe the problem clearly and build a harness around the work, Codex can help you move much faster.
```
