# Post-Event Pathway

The brochure describes a three-month post-event learning pathway. Use this page to plan what happens after the demo.

## After Today

- Identify the strongest user feedback.
- Keep one repo link and one demo script.
- Write the next three experiments.
- Find one mentor or partner who can validate the idea.
- Decide whether to pilot, pause or change direction.

## Three-Month Path

Month 1:

- Polish the prototype.
- Interview 5-10 target users.
- Replace guesses with evidence.

Month 2:

- Run one small pilot.
- Track one useful metric.
- Improve the product from feedback.

Month 3:

- Prepare a stronger portfolio artifact.
- Share outcomes with partners.
- Decide the next learning, funding or employment step.
